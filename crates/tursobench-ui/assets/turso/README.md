# Turso logomarks

Unmodified official PNGs downloaded from [Turso's brand page](https://turso.tech/brand)
on 2026-11-03. The page provides these files for use when referencing Turso.
Turso branding belongs to Turso; these assets are not original TursoBench artwork.

aqua for dark themes and dark teal for light themes. A separate check badge marks
successful Turso open history; it is painted by TursoBench, not part of the logo.
