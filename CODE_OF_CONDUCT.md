# Code of conduct

TursoBench welcomes contributors of all backgrounds and experience levels.
This code applies to project issues, pull requests, discussions and other
project-managed spaces, as well as anyone representing the project publicly.

## Expected behavior

- Be respectful, considerate and patient. Help people learn.
- Give constructive feedback about ideas and code; accept feedback in good faith.
- Respect differing experiences, identities and viewpoints.
- Protect others' privacy and respect requests to stop unwanted contact.

Harassment, discrimination, threats, sexualized attention, personal attacks,
doxxing and deliberate disruption are not acceptable.

## Reporting and enforcement

Report concerns to the repository maintainer,
[@pmfleming](https://github.com/pmfleming), through a private contact method listed
on their profile, if available. If none is available, open a project issue asking
for a confidential contact channel **without posting incident details or personal
information**. Do not use security advisories for conduct reports.

Maintainers should handle reports discreetly, share details only as needed to
investigate and respond, and consider context and impact. Responses may include
a warning, removal of content, restrictions on participation, or a temporary or
permanent ban. Retaliation against someone reporting a concern is unacceptable.
To request reconsideration, contact the maintainer with relevant context.
